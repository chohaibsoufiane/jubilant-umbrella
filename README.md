# Cinematic Printing Presentation

An interactive, cinematically-designed presentation on industrial printing processes, specifically focusing on **Offset** and **Flexography**.

### Features:
- **Cinematic Transitions**: Seamlessly transitions between complex grid layouts.
- **Dynamic Content**: Auto-triggered video animations and interactive trackers.
- **Premium Design**: Heavy focus on Swiss-grid and brutalist aesthetics with subtle background motifs.
- **Responsive Navigation**: Full keyboard and UI-based navigation controls.

### Technologies:
- HTML5 / Vanilla CSS3 / JavaScript
- Optimized Motion Physics (Transition Logic)
- Halftone and Motif Design-system

### Instructions:
- Open `index.html` in any modern web browser.
- Use **Left/Right arrows** or **navigation buttons** to move through the slides.
- **Final Slide Note**: The final slide requires a local video titled `video_animation.mp4` in the `media/` folder to play the concluding animation.
